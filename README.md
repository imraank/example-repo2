# Simple Sum Calculator

A beginner-friendly Python application that asks the user for two numbers and displays their sum.

## Features

- Accepts two numbers from the user
- Calculates the sum
- Handles invalid input with a helpful message

## How to Run

Make sure Python is installed, then run:

```bash
python sum_calculator.py
```

If your system uses Python 3 as `python3`, run:

```bash
python3 sum_calculator.py
```

## Example

```text
Simple Sum Calculator
---------------------
Enter the first number: 5
Enter the second number: 7
The sum of 5.0 and 7.0 is 12.0.
```
